- Multi-provider concurrent routing — zero-downtime 429 failover

- RPM sliding window (60s) per endpoint
- Exponential cooldown (2s→4s→8s...max 60s) on consecutive failures
- `isRateLimitError()`: 429, rate limit, quota exceeded, resource_exhausted
- Auto-registered into Engine from ProviderRegistry.listProviders()
- Engine.callLLM(): router.size > 1 → use router, else direct provider
