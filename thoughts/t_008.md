## Muhakeme
Foreman dosya sistemini persistence olarak kullanıyor.
Neden DB değil? 3 sebep:
1. Git-native — her düşünce version controlled
2. İnsan okunabilir — MD/YAML formatında, debug kolay
3. Basit — external dependency yok

Ama raw Thought/Chain interface'leri ile dosya formatı
aynı olmayabilir. Örneğin dosyada YAML frontmatter + markdown body
kullanılabilir. Veya sadece JSON. 

Karar: JSON dosyalar.
- thoughts/t_001.json
- chains/chain_001.json
- state.json (runtime state)

Neden MD değil? Thought'lar yapısal veri — parse etmek lazım.
MD güzel görünür ama parse etmesi fragile. JSON type-safe.

Ama thought dosyalarının YANINDA insan-okunabilir MD versiyonu da
olabilir. Bunu sonra ekleriz. Şimdilik sadece JSON.

state.json — global state machine durumu:
- currentState
- activeChainId
- activeThoughtId
- history (son N geçiş)
