## Muhakeme
ThoughtManager, thought'ları JSON dosyalar olarak yönetir.
Her thought `thoughts/t_xxx.json` dosyasında yaşar.

Tasarım kararları:

1. ID üretimi nasıl?
   → Auto-increment: mevcut dosyaları tara, en büyük id + 1.
   → Format: "t_001", "t_002", ... (3 haneli, padding)
   → 999'dan sonra 4 hane: "t_1000". Pratikte 999 yeterli.

2. create() neyi almalı?
   → Tam Thought nesnesi değil — bazı alanlar (id, createdAt, status)
   otomatik doldurulmalı. Partial input + defaults.
   → CreateThoughtInput tipi tanımlayacağım.

3. get() null mı dönmeli yoksa hata mı?
   → null dönsün. Caller karar versin.

4. update() partial mı tam mı?
   → Partial — sadece değişen alanlar. Spread ile merge.

5. list() filter'sız mı?
   → Opsiyonel filter: chainId, status, layer.

6. Dizin yoksa ne olur?
   → create() sırasında mkdirSync ile otomatik oluştur.
