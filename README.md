# Foreman

## Overview
Foreman is a project-scoped AI coding orchestrator designed to enforce discipline, parallel execution, and tactical reasoning in automated software development. Unlike standard chat-based agents, Foreman operates through a structured **4-Layer Forge Pipeline**, decomposing high-level tasks into atomic units of work that are researched, validated visually, and executed with precision.

It is a full codebase manipulator capable of multi-agent parallel execution, headless browser verification, automated git workflows, and autonomous refactoring.
