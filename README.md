## 🌌 The Vision
Most AI coding assistants act like glorified auto-complete tools. They write snippets, they fix typos, and they answer questions. **Foreman is not an assistant. Foreman is a Master Architect.**

Foreman operates on a fundamentally different paradigm: **Hyper-Fractal Decomposition**. When given a massive, complex task (like *"Build a complete auth system"* or *"Design an Awwwards-level Hero Section"*), Foreman doesn't just start writing code. It plans, it researches, it spawns specialized sub-agents, and it hammers every single pixel, byte, and logic gate into place until the masterpiece is complete.

## ⚙️ The Architecture of the Forge

Foreman doesn't just use one prompt to solve a problem. It passes your request through the **Forge Pipeline**, a 4-layer neural factory designed for absolute perfection:

### 1. 👁️ The Visioner (The Oracle)
Takes your raw idea and expands it into a comprehensive technical vision. It defines the exact acceptance criteria, the scope of work, and the boundaries of the masterpiece. 

### 2. ♟️ The Strategist (The Mastermind)
Takes the Vision and performs **Hyper-Fractal Decomposition**. It breaks the project down into massive *Blocks*, and then shatters those Blocks into tiny, hyper-focused *Atoms* (e.g., *Block 1: Hero Section -> Atom 1: Left CTA Button Margin -> Atom 2: Hover Animation Shadow*).

### 3. 🔍 The Researcher (The Scholar)
Before any code is written, the Researcher reads your existing codebase. It finds the patterns, reads the documentation, and extracts the context needed so the Worker never codes blindly. It spawns **Micro-Agents** to investigate specific architectural questions if needed.

### 4. 🔨 The Worker (The Blacksmith)
The Worker executes the Atoms. It hits the anvil. It uses the CLI, writes files, patches code, and runs tests. If an Atom fails the build, the Worker immediately rolls back the change, learns from the mistake, and strikes again.

## 🧬 Micro-Agent Orchestration & Self-Healing
Foreman is built to survive chaos. Its architecture includes state-of-the-art resilience mechanisms:

- 🦠 **Auto-Heal & Ghost Chain Clearing:** If an operation is violently interrupted, Foreman's `state.ts` engine automatically clears corrupted checkpoints, purges "ghost chains", and restarts the workflow with a clean slate. No manual intervention required.
- 🔄 **Provider Fallback Engine:** If the primary LLM provider fails or hits a rate limit (e.g., Antigravity 429 Resource Exhausted), Foreman seamlessly falls back to `gemini-3.1-pro-high` to ensure the hammer never stops swinging.
- 🧠 **Infinite Memory & Token Expansion:** Running on a massive 128,000-token thought budget and a 512,000-token chain budget, Foreman can swallow entire codebases, keep them in memory, and continuously synthesize millions of data points without losing context.

## 🚀 Getting Started

### Installation
```bash
git clone https://github.com/sovranamr/foreman.git
cd foreman
npm install
```

### The Two Modes of Foreman

**1. Direct Mode (For quick fixes & queries)**
Just chat with Foreman. It has 47+ tools at its disposal to read files, run bash commands, and make quick targeted edits.
```bash
./bin/foreman run "Fix the typo in the header component"
```

**2. The Forge Pipeline (For monumental creations)**
When you need to build something massive from scratch, invoke the `forge_pipeline`. This triggers the Hyper-Fractal process.
```bash
./bin/foreman run "Design a pixel-perfect, Awwwards-level Hero Section for a Dental Clinic. Use the Forge Pipeline."
```

## 🛡️ Security & Auditing
Foreman executes real shell commands and writes real files. It features a built-in **Approval Audit Trail** and strict path-security enforcement to ensure it never deletes your root directory or leaks your API keys.
